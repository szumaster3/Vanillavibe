### Informations:
- This modpack was designed with low-end PCs in mind and tested on older hardware configurations (loads faster than your mom running on a treadmill).
- For the best compatibility and overall experience, it is recommended to use the [Prism Launcher](https://prismlauncher.org/) to run this modpack.
- Java 16 or newer is recommended for the best compatibility and performance.
- This modpack was tested for over a year on servers hosted by [Crafthost](https://crafthost.pl/).

### Tests:
- Built and tested on actual potato PCs

  - CPU: Intel(R) Core(TM) i5-3320M CPU @ 2.60GHz
  - RAM: 16286 MiB (available: 10914 MiB)
